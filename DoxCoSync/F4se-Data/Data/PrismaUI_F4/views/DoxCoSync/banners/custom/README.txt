CoSync custom faction banners
=============================

Put your own banner images in this folder:

    Data\PrismaUI_F4\views\DoxCoSync\banners\custom\

* Formats: .png, .jpg, .jpeg, .webp, .svg
* File names: letters, numbers, "_", "-" and "." only, at most 48 characters
  (for example: minutemen_reborn.png)
* Shape: the banner is drawn 4:5 (portrait), e.g. 256 x 320 pixels.
* At most 8 MB per file and 64 images.

Files that cannot be used (spaces in the name, a .gif or .bmp, an empty or
damaged file, a PNG renamed to .jpg, the same image twice) are listed under
"Unusable Images" on the Banner screen with the reason and how to fix it.

Then open Multiplayer > Factions > Banner (or Create Faction) and choose it
under "Custom Image".

Only the file NAME is shared with other players, never the image itself.
Players who have a file with the same name in their own custom folder see
your image; everyone else sees the emblem and colour you picked with it.
